# 04. 계약 / 착수

> **이 단계의 본질**: **계약 조항이 향후 모든 분쟁의 기준**이 된다. 검수·대금·변경·하자·면책 조항을 여기서 사수하지 않으면 09~10 단계에서 반드시 폭탄이 터진다. 착수계·킥오프는 발주사와 **공통 언어**를 합의하는 자리다.

## 3. 6하원칙 가이드

### Who (누가)

| 역할 | 수행사 측 | 발주사 측 |
|---|---|---|
| **R** 실무 | 수행 PM, 법무, PMO | 발주 PM, 구매·법무 |
| **A** 책임 | 수행 임원 | 발주 책임자 |
| **C** 자문 | 영업(인계), 회계(대금) | 정보화팀장, 현업 |
| **I** 보고 | 본부장, 대표 | CIO |

### When (언제)
- 우선협상자 선정 ~ 계약 체결 (1~2주) ~ 착수계 제출 ~ 킥오프 (계약 후 1주 내)

### What (무엇을)
- **수행사가 작성·제출**: 착수계, 사업수행계획서, WBS, 의사소통계획서, 인력투입계획서, 보안서약서, 보증보험증권
- **발주사가 작성·교부**: 계약서, 착수통지서, 보안서약서 양식, 출입증
- **공동 의사결정**: 검수 기준, 변경관리 절차, 산출물 목록·서식, 회의체 운영

### Where (어디서)
- 계약 협상: 발주사 회의실 또는 화상
- 킥오프: 발주사 회의실 (대면 권장)
- 사업관리: 별도 협업 도구 (JIRA·Confluence·Notion·MS Teams 등) 사전 합의

### Why (왜)
- **계약 조항 = 분쟁 기준**. 모호한 조항은 발주사에 유리하게 해석되는 경향.
- **킥오프 = 첫인상**. 사업관리 체계가 부실하면 향후 신뢰 회복 불가.
- 변경관리 절차를 미리 못 박지 않으면 → "이 정도는 해주실 거죠?" 무상 요청 폭주.

### How (어떻게)
1. 계약 협상 의제 정리 (검수·대금·변경·하자·면책·지체상금)
2. 계약 체결
3. 착수계·보증보험·보안서약서 제출
4. 사업수행계획서·WBS·의사소통계획서 작성
5. 킥오프 미팅 (의제 §5-3)
6. 1차 주간보고 발송 (계약 후 1주 내)

## 4. ToDo 체크리스트

### 4-1. 계약 협상 (가장 중요)
- [ ] **검수 기준** 명문화 — "기능 100%·결함 Critical 0건·Major N건 이하" 등 정량
- [ ] **검수 기간** 명문화 — 검수 의뢰 후 N영업일 내 검수, 무응답 시 자동 검수 간주
- [ ] **대금 지급 일정** — 착수금·중도금·완료금 비율 + 검수 후 N일 내 지급
- [ ] **변경관리 절차** — 변경요청서·영향분석·승인·견적 변경의 단계 명문화
- [ ] **하자보수 범위·기간** — 하자 정의(원인·재현)·범위(추가 기능 제외)·기간(1~3년)
- [ ] **지체상금** — 율(일 0.05~0.15%)·상한(계약금액의 N%)
- [ ] **손해배상 한도** — 계약금액 또는 일부로 한도 설정
- [ ] **지식재산권 귀속** — 산출물·소스코드·노하우 분리
- [ ] **재위탁(하도급) 조항** — 발주사 사전 동의·재위탁 비율 한도

### 4-2. 착수 행정
- [ ] 착수계 제출 (발주사 양식)
- [ ] 보증보험 가입 (이행보증·하자보증)
- [ ] 보안서약서 (PM·핵심 인력·재위탁사)
- [ ] 출입증 신청 + 보안 교육 일정 확인
- [ ] 발주사 시스템 계정 신청 (이메일·VPN·이슈관리·문서함)

### 4-3. 사업관리 체계
- [ ] 사업수행계획서 작성·제출
- [ ] WBS 작성 (Phase 단위)
- [ ] 의사소통계획서 (회의체·보고서·채널·주기)
- [ ] 인력투입계획서 (등급·M/M·기간)
- [ ] 리스크관리대장·이슈관리대장 초기 등록
- [ ] 협업 도구 합의 + 사용 권한 부여

### 4-4. 킥오프
- [ ] 킥오프 의제 사전 회람
- [ ] 킥오프 회의록 (의사결정·후속조치)
- [ ] 1차 주간보고 발송

## 5. 핵심 산출물 + 샘플

### 5-1. 계약 핵심 조항 체크 (협상 의제 시트)

| 조항 | 발주사 초안 위험 시그널 | 우리가 사수할 것 |
|---|---|---|
| 검수 | "발주사가 만족할 때까지" | 정량 기준 (결함률·기능 100%·SLA) |
| 검수기한 | 명시 없음 | "검수 의뢰 후 10영업일 내, 무응답 시 검수 간주" |
| 변경 | 명시 없음 | 변경요청서·영향분석·견적 변경 절차 |
| 하자 | "모든 결함" | 원인이 우리 귀책인 결함만 + 신규 기능 요청 제외 |
| 지체 | 율·상한 명시 없음 | 일 0.05~0.15%, 상한 계약금액 10% |
| 손해 | 무한 책임 | 계약금액 한도 |
| 지재권 | "발주사 일체 귀속" | 우리 사전 보유 재산·범용 라이브러리 분리 |

### 5-2. 사업수행계획서 표준 목차

```
1. 사업 개요 (목적·범위·기간·금액)
2. 추진 체계 (조직도·RACI·역할·책임)
3. 일정 계획 (마일스톤·WBS 요약·검수일)
4. 인력 운영 (등급·M/M·투입·교체 기준)
5. 산출물 계획 (단계별 산출물 목록·서식·검수)
6. 품질관리 (검토·테스트·코드품질·결함관리)
7. 위험관리 (식별·평가·대응·모니터링)
8. 보안관리 (출입·계정·자료·서약)
9. 변경관리 (절차·양식·승인)
10. 의사소통 (회의체·보고서·채널·주기)
11. 교육·인수인계·하자보수 계획
부록: WBS 상세, 인력 이력서, 양식
```

### 5-3. 킥오프 표준 의제

| # | 의제 | 발표·결정 |
|---|---|---|
| 1 | 사업 개요 재확인 (범위·일정·금액) | 발주사 PM, 수행사 PM |
| 2 | 양사 조직 소개 + RACI 합의 | 양측 PM |
| 3 | 의사소통 채널·주기 합의 | 수행사 PM |
| 4 | 산출물 목록·서식 합의 | 수행사 PMO |
| 5 | 변경관리 절차 합의 | 수행사 PM |
| 6 | 보안·출입·계정 절차 안내 | 발주사 보안 |
| 7 | 1차 주간보고 일자·양식 합의 | 양측 |
| 8 | 다음 회의 일정 (분석 인터뷰 등) | 양측 |

### 5-4. 의사소통계획서 (간이 양식)

| 회의체 | 주기 | 참석자 | 산출물 | 채널 |
|---|---|---|---|---|
| 주간보고 회의 | 매주 1회 | 양측 PM·PL | 주간보고서 | 대면/화상 |
| 월간 운영위 | 월 1회 | 양측 임원 | 월간보고서 | 대면 |
| 일일 스탠드업 (수행사 내부) | 매일 15분 | 수행사 PL·개발자 | 진척 메모 | 대면/슬랙 |
| 변경관리회의 | 비정기 | 양측 PM·요청자 | 변경요청서·결정문 | 대면/화상 |
| 위험관리회의 | 격주 | 양측 PM·PMO | 위험관리대장 갱신 | 화상 |

## 6. 리스크 & 흔한 실수

| 리스크 | 영향 | 대응 |
|---|---|---|
| 검수 기준 정성 표현 ("만족할 때") | 검수 무한 지연 → 대금 지연 | 정량 기준 사수, 협상 결렬 시 수주 포기 검토 |
| 변경관리 절차 부재 | 무상 추가 과업 폭주 | 킥오프 시 절차 합의 + 첫 변경 요청 시 즉시 절차 가동 |
| 산출물 목록·서식 미합의 | 검수 시 "양식 다르다" 반려 | 킥오프 시 목록·서식 별표로 합의 |
| 발주사 양식 강제 + 우리 표준과 충돌 | 작성 공수 증가 | 양식 비교표 작성 → 핵심 항목만 매핑 |
| 보안서약서 무제한 책임 | 인력 개인까지 책임 전가 | 회사 단위 책임으로 협상, 개인 책임은 회사 가입 보험 한도 |
| 킥오프 의제 부실 | 첫인상·신뢰 손실 | 킥오프 1주 전 의제·자료 회람 |

## 8. 역추적(Backfill) 가이드

다른 사 제안 통과 후 PM 투입 등으로 04부터 진입한 경우:

| 누락 항목 | 보완 방법 |
|---|---|
| 03 제안서·견적·약속 인수 부족 | 영업·전임 PM에게 **인수인계서** 작성 요청 — 약속한 인력·일정·범위·암묵적 합의 전수 |
| RFP 정독 미완 | 1주 내 RFP·질의응답 회신 정독 + 모호 항목 표 작성 |
| 발주사 키맨 미파악 | 킥오프에서 명함 교환 + RACI 합의 시 1:1 매칭 |
| 계약 협상이 이미 끝남 | 우리가 불리한 조항 식별 → 변경관리 절차에서 보완 가능한 항목 분류 |
| 킥오프가 이미 끝남 | "재정렬 미팅" 명목으로 1주 내 별도 미팅 — 산출물·서식·소통 재합의 |
