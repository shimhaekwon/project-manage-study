#### 4.1.1 SAST-INQ-001 (High) — JWT 검증 시 Algorithm none 우회 가능성

| 항목 | 내용 |
|---|---|
| 발견 | 정적분석 — JWT 라이브러리 설정에서 `algorithm` 미명시 |
| 영향 | 공격자가 JWT 서명 우회 가능 (이론적) |
| 조치 | `algorithm: HS256` 명시 강제 + 검증 단계 화이트리스트 |
| 검증 | UT-AUTH-021 추가 — none algorithm 거부 시험 통과 |
| 상태 | **Closed** |
