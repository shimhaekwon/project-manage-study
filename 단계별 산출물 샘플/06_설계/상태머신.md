## 1. 상태 정의

| 상태 | 코드 | 의미 | 진입 시점 |
|---|---|---|---|
| **NEW** | NEW | 신규 접수 (답변 대기) | 문의 등록 시 자동 (FR-INQ-001) |
| **ANSWERED** | ANSWERED | 답변 완료 (고객 확인 대기) | 상담사 답변 작성 시 자동 (FR-INQ-002) |
| **REOPENED** | REOPENED | 고객 추가 질문 (재답변 대기) | 답변 후 7일 이내 고객 추가 등록 |
| **CLOSED** | CLOSED | 종결 (수정 불가) | 답변 확인 또는 7일 경과 시 자동 |
| **CANCELLED** | CANCELLED | 취소 (등록자 본인 또는 관리자) | NEW 상태에서 취소 (FR-INQ-006) |

> **DELAYED 상태는 별도 신설 X**. SLA 미달은 화면에서 sla_due_dt 비교로 표시 (06 §6 거부 항목).

## 3. 전이 규칙 (전수표)

| # | 현재 상태 | 다음 상태 | 트리거 | 권한 | 검증 | 트랜잭션·후속 |
|---|---|---|---|---|---|---|
| T-1 | (없음) | NEW | FR-INQ-001 등록 | GUEST 이상 | 제목·내용·카테고리·첨부 검증 | INSERT INQUIRY + ATTACHMENT 1트랜잭션 / SLA 알림 큐 적재 |
| T-2 | NEW | ANSWERED | FR-INQ-002 답변 등록 | AGENT 이상 | (1) 본인 또는 권한 (2) 동시성 락 검증 | INSERT ANSWER + UPDATE INQUIRY (status, mod_id, mod_dt, version+1) / 답변 메일 비동기 발송 / SLA 알림 큐 제거 |
| T-3 | NEW | CANCELLED | FR-INQ-006 취소 | GUEST 본인만 | (1) 본인 검증 (2) status='NEW' 검증 | UPDATE INQUIRY (status, mod_id, mod_dt, version+1) / SLA 알림 큐 제거 |
| T-4 | ANSWERED | REOPENED | 고객 추가 질문 | GUEST 본인 (등록자) | (1) 본인 검증 (2) 답변 후 7일 이내 (3) status='ANSWERED' | UPDATE INQUIRY (status, mod_id, mod_dt, version+1) — SLA 재기산 X |
| T-5 | REOPENED | ANSWERED | FR-INQ-002 추가 답변 | AGENT 이상 | (1) 권한 (2) 동시성 락 | T-2와 동일 (단, 답변 메일은 추가 답변 안내) |
| T-6 | ANSWERED | CLOSED | 고객 확인 (자동) | (시스템) | status='ANSWERED' | UPDATE INQUIRY (status='CLOSED') |
| T-7 | ANSWERED | CLOSED | 7일 경과 (배치) | (시스템 배치) | status='ANSWERED' AND last_answered_dt < now - 7일 | 일 1회 배치 자동 처리 |
| T-8 | NEW | CLOSED (자동) | (정책) — Phase 2 검토 | — | — | Phase 1 미적용 |

## 4. 전이 거부 규칙 (보안·정합성)

다음 전이는 **모두 거부**하고 적절한 에러 코드로 응답:

| # | 시도 | 거부 응답 | 사유 |
|---|---|---|---|
| D-1 | ANSWERED → CANCELLED | 409 CONFLICT (INVALID_STATE) | 답변 완료 후 취소 불가. 고객은 새 문의 등록으로 처리 |
| D-2 | CLOSED → 어떤 상태든 | 409 CONFLICT | 종결된 문의는 변경 불가 |
| D-3 | CANCELLED → 어떤 상태든 | 409 CONFLICT | 취소된 문의는 변경 불가 |
| D-4 | NEW → ANSWERED (GUEST 시도) | 403 FORBIDDEN | GUEST는 답변 권한 없음 |
| D-5 | ANSWERED → REOPENED (7일 초과) | 409 CONFLICT (TIME_EXPIRED) | 7일 초과 시 새 문의 등록 안내 |
| D-6 | NEW → CANCELLED (다른 GUEST 시도) | 403 FORBIDDEN | 본인만 취소 가능 |
| D-7 | NEW → CANCELLED (status 이미 변경됨, 동시성) | 409 CONFLICT (VERSION_MISMATCH) | 낙관적 락 충돌 |

## 5. SLA 정책과의 정합 (요구사항정의서 v1.1 §3.4)

| 시나리오 | SLA 기준 | 알림 발송 |
|---|---|---|
| NEW 상태 | 등록시각 + 24시간 | 마감 4시간 전 (FR-INQ-004) |
| ANSWERED → REOPENED | **재기산 X** — 최초 등록시각 + 24시간 유지 | 알림 대상 X (이미 1차 답변 완료) |
| REOPENED 상태 | (재기산 X) | 알림 대상 X |
| CLOSED·CANCELLED | (해당 없음) | 큐에서 제거 |

> **명시적 결정**: REOPENED 시 SLA 재기산하지 않음 (요구사항정의서 §3.4 + 본 문서 §3 T-4)

## 6. 답변 1:N (REOPENED 대응)

상태머신 + 데이터 모델 정합:

```
INQUIRY.status: NEW → ANSWERED → REOPENED → ANSWERED → CLOSED
ANSWER 테이블:                    +1건       +1건
                                                       (총 2건)
```

| 이벤트 | INQUIRY 상태 | ANSWER 행 |
|---|---|---|
| 등록 | NEW | 0 |
| 1차 답변 | ANSWERED | +1 (총 1) |
| 추가 질문 | REOPENED | (변동 없음, 1) |
| 2차 답변 | ANSWERED | +1 (총 2) |
| 7일 경과 자동 | CLOSED | (변동 없음, 2) |

> ANSWER는 **1 INQUIRY 1:N**, 모두 USE_YN='Y' 보존 (이력 추적).

## 7. 데이터 변경 정책

| 상태 | INQUIRY 컬럼 변경 가능 | ANSWER 추가 가능 | ATTACHMENT 추가 가능 |
|---|---|---|---|
| NEW | ✅ (제목·내용·카테고리·첨부 — GUEST 본인만, 24h 이내) | — | ✅ |
| ANSWERED | — | — (T-5 진입까지 대기) | — |
| REOPENED | — | ✅ (T-5) | — |
| CLOSED | — | — | — |
| CANCELLED | — | — | — |

> 단순 정책: NEW 외에는 INQUIRY 본문 수정 불가. 답변 추가는 ANSWERED → REOPENED 후만.
