## 1. 화면 목록 (사이트맵)

```
[로그인] (SCR-AUTH-001)
   ├─ [GUEST]
   │     ├─ 본인 문의 목록 (SCR-INQ-LIST-002)
   │     ├─ 문의 등록     (SCR-INQ-FORM-001)
   │     └─ 문의 상세     (SCR-INQ-DTL-001)
   ├─ [AGENT]
   │     ├─ 전체 문의 목록 (SCR-INQ-LIST-001)
   │     └─ 문의 상세      (SCR-INQ-DTL-001)
   └─ [ADMIN]
         ├─ 전체 문의 목록    (SCR-INQ-LIST-001)
         ├─ 문의 상세          (SCR-INQ-DTL-001)
         └─ SLA 통계 대시보드  (SCR-INQ-STAT-001)
```

| 화면 ID | 화면명 | 접근 권한 | 관련 요구사항 |
|---|---|---|---|
| SCR-AUTH-001 | 로그인 | 전체 (비로그인) | NFR-INQ-003 (인증) |
| SCR-INQ-LIST-001 | 전체 문의 목록 | AGENT, ADMIN | FR-INQ-003 |
| SCR-INQ-LIST-002 | 본인 문의 목록 | GUEST | FR-INQ-003 |
| SCR-INQ-FORM-001 | 문의 등록 | GUEST (등록자) | FR-INQ-001 |
| SCR-INQ-DTL-001 | 문의 상세 (답변·취소 포함) | 전체 (권한별 표시 차이) | FR-INQ-002, FR-INQ-006 |
| SCR-INQ-STAT-001 | SLA 통계 대시보드 | ADMIN | FR-INQ-005 |

> 본 문서는 6개 화면 모두를 다루지만 분량 절제를 위해 핵심 5개 (LIST-001 / FORM-001 / DTL-001 / STAT-001 / LIST-002) 만 풀 명세. SCR-AUTH-001은 표준 로그인 화면이라 부록으로 처리.

## 2. 공통 표준

### 2.1 레이아웃 (모든 화면 공통)

```
┌──────────────────────────────────────────────┐
│  Header: 로고 / 사용자명 (마스킹) / 로그아웃 │
├──────────────────────────────────────────────┤
│  Nav: 메뉴 (역할별 표시)                     │
├──────────────────────────────────────────────┤
│                                              │
│  Main Content                                │
│                                              │
├──────────────────────────────────────────────┤
│  Footer: 회사명 / 보안등급 (대외비)          │
└──────────────────────────────────────────────┘
```

### 2.2 공통 컴포넌트

| 컴포넌트 | 용도 |
|---|---|
| 토스트 (Toast) | 성공·정보 메시지 (3초 자동 사라짐) |
| 다이얼로그 (Dialog) | 확인·취소 액션 (예: 취소 확인) |
| 로딩 스피너 | API 호출 중 (>200ms일 때만 표시) |
| 페이지네이션 | 목록 화면 (size 20 기본) |
| 빈 상태 (Empty) | 검색 결과 0건 시 안내 |

### 2.3 색상·상태 표시 규칙 (DELAYED 화면 표시 — 별도 상태 신설 X)

| 상태 | 배지 색상 | 비고 |
|---|---|---|
| NEW | 회색 | 신규 |
| ANSWERED | 초록 | 답변 완료 |
| REOPENED | 주황 | 재오픈 |
| CLOSED | 진회색 | 종료 |
| CANCELLED | 회색 (취소선) | 취소 |

> **SLA 시각 표시**: `sla_due_dt - 현재시각 < 4h`이면 배지 옆에 🔴 (빨강 점) 표시, `< 0`이면 "SLA 초과" 라벨. 별도 STATUS 컬럼 추가 X (06 §6 거부 항목).

| 상황 | 메시지·동작 |

## 6. SCR-INQ-LIST-002 — 본인 문의 목록 (GUEST)

### 6.1 개요·차별점

| 항목 | 내용 |
|---|---|
| 화면 ID | SCR-INQ-LIST-002 |
| 화면명 | 본인 문의 목록 |
| 접근 권한 | GUEST |
| 관련 API | API-INQ-MY-001 (GET /api/my/inquiries) |

### 6.2 추가 항목

- 우상단 [+ 새 문의 등록] 버튼 → SCR-INQ-FORM-001 이동
- 본인이 취소한 문의(CANCELLED)도 표시 (회색 + 취소선)

> 와이어프레임은 SCR-INQ-LIST-001과 거의 동일하므로 생략 (등록자 컬럼 제거 + [+ 새 문의 등록] 버튼만 차이).
