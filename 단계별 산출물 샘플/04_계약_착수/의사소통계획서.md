# 의사소통계획서 — Helpdesk Lite

## 1. 목적

양측 의사소통을 회의체·주기·산출물·채널로 표준화하여 (1) 정보 누락 방지 (2) 의사결정 추적 (3) 분쟁 시 증빙 확보를 보장한다.

## 3. 보고서 표준

### 3.1 주간보고서 (매주 금요일)

| 섹션 | 내용 |
|---|---|
| 표지 | 보고 회차·기간·작성자·수신자 |
| 진척 요약 | 전체 % (계획 vs 실적) + 신호등 (Green/Yellow/Red) |
| 모듈별 진척 | inquiry-core / inquiry-search / inquiry-sla-notifier / inquiry-stats / FE — 각 진척률 |
| 이번 주 실적 | 3~5개 bullet |
| 다음 주 계획 | 3~5개 bullet |
| 이슈·위험 | 신규·진행·종결 |
| 발주사 요청사항 | 회신 기한 명시 |
| 인력 현황 | 등급·M/M·교체 여부 |
| 별첨 | 진척표·결함현황·위험관리대장 |

> 양식 상세는 07 단계 §5-1 참조 / 실 샘플은 `07_개발/주간보고서.md` 참조.

### 3.2 월간보고서 (운영위)

| 섹션 | 내용 |
|---|---|
| 1. 사업 진척 | 마일스톤 달성·전체 진척률 |
| 2. 단계별 산출물 | 작성·검수·승인 현황 |
| 3. 품질 | 결함·테스트·코드품질 추이 |
| 4. 이슈·위험 | Top 5 |
| 5. 변경관리 | CR-NNN 처리 현황 |
| 6. 인력 | 투입·교체·만족도 |
| 7. 다음 달 계획 | 마일스톤·주요 활동 |
| 8. 의사결정 요청 | 임원 결재 항목 |

### 3.3 마일스톤 종료보고 (M1~M5)

| 섹션 | 내용 |
|---|---|
| 1. 마일스톤 정의 | 기준 산출물·합격 조건 |
| 2. 산출물 목록 | 작성·검수·승인 현황 |
| 3. 품질 게이팅 | 통과 항목 |
| 4. 잔존 이슈 | Critical·High 0 확인 |
| 5. 다음 단계 진입 가능성 | Go/No-Go |

## 4. 채널·도구

| 채널 | 용도 | 비고 |
|---|---|---|
| 이메일 (공식) | 계약·승인·증빙 | 양측 PM·임원 회람 필수 |
| 협업 도구 (Confluence/Notion) | 문서 공유·검토 | 발주사 정보화팀 합의 후 결정 |
| 이슈관리 (JIRA/Redmine) | 이슈·결함·변경 | 발주사 사내 도구 사용 권장 |
| 채팅 (Teams/Slack) | 일상 소통 | 대화 기록 공식 의사결정 X — 메일·문서로 확정 |
| 형상관리 (GitLab/GitHub) | 소스·문서(MD) | 발주사 사내 GitLab 사용 |
| 화상회의 (Zoom/Teams) | 원격 회의 | 회의 녹화는 양측 동의 시만 |

       ↓                                ↓

       ↓
