### 5.1 단계별 산출물 목록 (전수)

분석·설계·개발·테스트·인수 5단계 모든 산출물은 별도 **산출물 목록서** (09 인수인계 단계에서 양측 점검) 참조. 본 계획서에서는 단계별 대표만 명시.

| 단계 | 대표 산출물 |
|---|---|
| 분석 | 요구사항정의서·RTM·인터뷰결과서·NFR 체크리스트 |
| 설계 | DB·화면·API·아키텍처·보안·IF·권한매트릭스·상태머신 |
| 개발 | 소스코드 (Git tag)·단위테스트결과서·형상관리계획서·주간보고 |
| 테스트 | 통합테스트시나리오·UAT결과서·성능/보안 시험성적서·결함관리대장 |
| 인수 | 컷오버계획서·이행결과서·산출물목록·인수인계서·검수확인서 |

- 표지: 산출물명·프로젝트·버전·작성·검토·승인·일자

- 승인: 양측 4~5명 서명란

## 11. 교육·인수인계·하자보수 계획

- 관리자 1일 (4시간) + 일반 사용자 1일 (2시간)

- 산출물 전수 + 운영매뉴얼 + 핵심 비밀번호 (봉인)

- 하자 정의: **우리 귀책 결함**만 + 신규 기능 요청 제외
